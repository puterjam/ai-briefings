## 🔥 重磅更新

### 1. OpenClaw v2026.10.10-beta.1 发布 📌 一手信源
- **OpenClaw** (2026-10-15): 最新 beta 版本带来显著性能提升——Gateway 的聊天回合、会话列表、启动和空闲状态大幅减少 SQLite 和主线程工作，数据库操作迁移到 worker 线程，大型 Agent 集群在高负载下保持响应。
- **更新可靠性大幅改善**：从 2026.10.1 及更早版本的升级可以正常完成，忙碌的 Gateway 和缓慢的 Doctor 步骤不再拒绝或回滚更新，失败的更新不再留下半安装版本。
- **重启安全回复**：中断和未完成的回复在 Gateway 重启后恢复，被监视的子结果、排队回合、已接受的 Agent 更新和操作员任务在重启后不再消失。
- **云会话**：支持在本地和云之间移动会话，通过环境配方和验证的 Node 工具链按仓库组织云环境。
- **新模型支持**：Gemini 4 Argon 成为默认 Gemini 模型。
- [查看详情](https://github.com/openclaw/openclaw/releases/tag/v2026.10.10-beta.1)

### 2. OpenClaw v2026.9.33 扩展稳定版发布 📌 一手信源
- **OpenClaw** (2026-10-15): 这是 gateway-only 的扩展稳定版（相当于 LTS），包含 9 月底版本加关键安全更新、可靠性和性能修复。
- **更安全的升级**：2026.9 系列的更新保持状态、插件数据、服务所有权和 Windows 状态路径完整。
- **新模型支持**：Meta Muse Wonder、MiniMax M3.1 思考力度级别、MiniMax 门户 OAuth 令牌过期后保持登录。
- **模型回合更可靠**：Agent 运行遵循实时思考级别，本地提供商获得响应头截止时间，ChatGPT WebSocket 正常关闭恢复，Codex 回复保留最终令牌。
- [查看详情](https://github.com/openclaw/openclaw/releases/tag/v2026.9.33)

### 3. Anthropic 扩大网络安全验证计划 (CVP) 📌 一手信源
- **Anthropic** (2026-10-06): 推出扩展版网络安全验证计划，向合格安全专业人员提供高级网络安全功能和减少阻断的分类器。
- 计划包含**三个访问层级**：Defense Access（防御访问）、Red Team Access（红队访问），以及更高级别，每层包含不同验证要求和安全控制。
- 涵盖 Claude Opus 5.5、Claude Sonnet 5.5、Claude Mythos 5.1 等最新模型。
- 整合了此前的 Project Glasswing 和 CVP 两个项目。
- [查看详情](https://www.anthropic.com/news/cyber-verification-program)

### 4. Anthropic 启动独立评估员计划 📌 一手信源
- **Anthropic** (2026-10-15): 宣布开始向独立第三方评估机构开放员工级访问权限，首个合作方为非营利组织 METR。
- METR 将发布其风险评估结果，同时 Anthropic 还在与 SecureBio、Accenture 合作，并与 Hugging Face 等组织进行早期讨论。

- [查看详情](https://www.anthropic.com/news/an-update-on-independent-evaluators)
